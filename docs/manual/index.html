The main window

The window is a tabbed shell. Each tab is an independent tool; nothing one tab does affects another unless they share the same underlying game files. A persistent status bar runs along the bottom, with two segments:

  • Left — the configured Starfield install path, or a warning if none is set yet.
  • Right — the current task description (for example, Reading ESM list…, Checking for updates…).
Tip The tool tolerates being closed and reopened mid-task. Nothing is written to disk until you explicitly confirm (Apply in the diff dialog, Save Snapshot, etc.).
