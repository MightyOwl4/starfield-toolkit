Feature highlights

012 — Dependency Inspector
New read-only tab: centered grid of installed creations with side connectors visualising hard and soft dependencies, directed-closure highlight on selection, and warnings for hard dependencies pointing at uninstalled creations. See Dependency Inspector.
011 — Fast Lane category refinement
Added SAFE and LOW_RISK category buckets to the Fast Lane check, cutting cosmetic false-positives. See Fast Lane Check.
010 — Diff connectors & hints
Colored Bezier connectors between diff panels and per-move Hint dialog showing every constraint considered. See Diff dialog.
009 — Fast Lane creation check
New tab: check installed (or imported) creations against the April 2026 baseline.
008 — Description dependency parser
Offline LLM pipeline producing curated rule books from creation descriptions. See Description parser.
007 — Load order rule books
User and curated rule books with an editor. See Rule Books tab.
006 — TES4 master dependency sorting
Hard-gate sorter reading plugin headers; non-bypassable Apply-time validation.
005 — Creations text catalogue
Offline scraper enumerating all ~5K creations, feeding 008 and 009.
004 — Grid modes & details dialog
Text list / rich media toggle, reusable details modal.
003 — Load order sorting tool
Drag-and-drop plus Auto-Sort with diff view.
002 — API response caching
Persistent cache with immutable/volatile field split and session staleness windows.
001 — Tabbed GUI toolbox
Initial shell, game-path detection, status bar, installed creations list.
