# Data Model: Fast Lane Creation Check

**Date**: 2026-04-10 | **Branch**: `009-fast-lane-check`

## Entities

### BaselineSnapshot (file on disk)

The bundled trimmed catalogue used as the pre-Fast-Lanes reference.

**Location**:
- Production (PyInstaller): `sys._MEIPASS/data/creations_baseline.json`
- Development: `<project_root>/data/creations_baseline.json`

**Schema**:
```json
{
  "version": 1,
  "snapshot_date": "2026-04-06T12:00:00Z",
  "entries": {
    "<content_id>": {
      "title": "string",
      "author": "string",
      "version": "string"
    }
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| version | integer | Schema version for future migrations (current: 1) |
| snapshot_date | string (ISO 8601) | UTC timestamp when the baseline was cut |
| entries | dict[content_id → entry] | Creations keyed by content_id for O(1) lookup |
| entries[].title | string | Display name |
| entries[].author | string | Author display name (tiebreaker for title lookups) |
| entries[].version | string | Latest version at snapshot time (from release_notes) |

**Lifecycle**:
- Immutable in any given app build
- Regenerated by `make_baseline.py` before a release cut
- Never modified at runtime

### CreationCheckResult (in-memory, per row)

Runtime representation of one creation in the check result list.

| Field | Type | Description |
|-------|------|-------------|
| content_id | string | UUID of the creation |
| title | string | Display name (from input source) |
| author | string | Author name |
| baseline_version | string \| None | Version from the baseline, or None if not in baseline |
| current_version | string \| None | Version from the creations cache or exported list |
| status | enum | "updated" / "not_updated" / "unknown" |
| in_baseline | bool | True if content_id found in baseline |
| reason | string | Short explanation of how status was determined (for tooltip/details) |

**Status classification**:
- `"updated"`: `in_baseline=True`, both versions present, `current > baseline`
- `"not_updated"`: `in_baseline=True`, both versions present, `current == baseline`
- `"unknown"`: missing baseline entry, missing current version, or version comparison failed

**Highlight**: Only `"not_updated"` rows are visually highlighted.

### InputSource (conceptual)

Two modes, both producing a list of `CreationCheckResult` seeds.

#### Mode 1: Installed Creations (default)
Source: `build_creation_list(game_install)` from `starfield_tool.parsers`.
Provides: content_id, title, author, installed_version, plus cached `available_version` from `get_cached_info_any()`.

#### Mode 2: Imported File
Source: CSV or Markdown file produced by the Installed Creations tab's `_export()` method.

**New format** (updated by this feature):
```csv
#,Content ID,Name,Author,Installed Version,Date
1,"4bd2936a-139f-4177-a4c8-2ab26261bb74","Dynamic Universe","youngneil1","2.2","29 Jan 2026"
```

**Fields used by Fast Lane Check**:
- `Content ID` — primary matching key into baseline
- `Installed Version` — the version to compare against baseline
- `Name`, `Author` — displayed in results; used as fallback matching for legacy exports

**Legacy compatibility**: Exports created before this feature lack the `Content ID` column. The import parser detects header shape and falls back to `(Name, Author)` tuple matching, showing a warning to the user.

## Relationships

- `BaselineSnapshot` is the reference dataset — static, bundled, read-only
- `CreationCheckResult` joins input source data (current state) with `BaselineSnapshot` entries (reference state) via content_id or title fallback
- The creations cache (from `starfield_tool.creations`) provides the `current_version` used in comparisons — this is populated by the Installed Creations tab's "Check for Updates"
- Results are displayed in a Treeview but not persisted — the tool is stateless between sessions

## Data Volume Estimates

- **Baseline file size**: ~200 KB for 4,954 creations (compact JSON, ~40 bytes per entry)
- **In-memory footprint**: negligible (a single dict + result list of < 1000 rows)
- **Bundled size impact**: < 500 KB added to the PyInstaller distribution
